## 🌱 入门路径：从零到 Agent

**目标**：理解为什么 Agent 存在，掌握最基本的循环机制。

### 路线

```
examples/00-hello-llm
        ↓
examples/01-manual-loop
        ↓
examples/02-tool-calls
```

### 每个阶段学什么

| 阶段 | 示例 | 核心问题 | 你将掌握 |
|------|------|---------|---------|
| 1 | `00-hello-llm` | "直接调 LLM API 有什么问题？" | 流式输出、`fetch` + `TextDecoder`、Mock 模式 |
| 2 | `01-manual-loop` | "为什么需要循环？" | Agent = LLM + Tools + Loop、消息类型、状态传递 |
| 3 | `02-tool-calls` | "工具是怎么被调用的？" | Schema 定义、参数校验、并行执行、错误恢复 |

### 完成标准

- [ ] 能独立解释：Agent 和 ChatBot 的本质区别是什么？
- [ ] 能手写一个最小 `agentLoop`（伪代码即可）
- [ ] 能定义一个带 Schema 的工具，并解释 `Type.Object` 的作用

---

## 🌿 进阶路径：从零件到整车

**目标**：理解完整架构，能把 Demo 组合成可交互的应用。

### 路线

```
examples/03-event-stream
        ↓
examples/04-session-context
        ↓
examples/05-steering-abort
        ↓
examples/06-mini-agent-cli
        ↓
      playground/
```

### 每个阶段学什么

| 阶段 | 示例 | 核心问题 | 你将掌握 |
|------|------|---------|---------|
| 4 | `03-event-stream` | "UI 怎么知道 LLM 输出了什么？" | 事件驱动架构、Observer 模式、解耦订阅者 |
| 5 | `04-session-context` | "对话历史怎么管理？" | Session 类、上下文修剪、`maxTurns` 保护 |
| 6 | `05-steering-abort` | "用户能中途打断吗？" | `AbortController`、Steering 注入、队列模式 |
| 7 | `06-mini-agent-cli` | "所有零件怎么拼起来？" | 交互式 CLI、命令解析、全功能 Agent |
| 8 | `playground/` | "怎么做成 Web 应用？" | React + Fastify + SSE、前后端联调 |

### 完成标准

- [ ] 能画出 Agent 的事件流图（从用户输入到 UI 更新）
- [ ] 能解释 `steer()` 和 `followUp()` 的时序差异
- [ ] 能独立启动 `playground` 的前后端，并进行一次完整对话

## 🌳 高阶路径：从能用到好用

**目标**：具备生产环境部署和扩展的能力。

### 路线

```
docs/guide/01-why-agent ──→ ... ──→ docs/guide/11-types-interfaces
              ↓
      扩展 playground：添加新 LLM 提供商
              ↓
      扩展 playground：添加自定义工具
              ↓
      阅读 docs/project/09-real-llm-provider
              ↓
      阅读 docs/project/10-production-checklist
              ↓
      部署上线
```

### 每个阶段学什么

| 阶段 | 内容 | 核心问题 | 你将掌握 |
|------|------|---------|---------|
| 9 | `docs/guide/` 全部 | "每个设计决策背后的原因？" | 完整理论体系、类型系统、源码导航 |
| 10 | 添加新提供商 | "怎么支持国产模型？" | `LLMProvider` 接口、工厂注册、配置管理 |
| 11 | 添加自定义工具 | "怎么让 Agent 操作我的数据库？" | 工具定义、安全校验、前后置钩子 |
| 12 | 生产检查清单 | "上线前还要做什么？" | 安全、监控、部署、测试、容错 |

### 完成标准

- [ ] 能为 playground 添加一个新的 LLM 提供商（如 DeepSeek、Claude）
- [ ] 能编写一个访问真实 API 的自定义工具
- [ ] 能列出生产部署的 5 个关键检查项

### 常见跳转场景

| 如果你... | 建议跳到... |
|-----------|------------|
| 跑完 Demo 2 后好奇"事件怎么驱动 UI 的？" | 直接跳到 `03-event-stream` |
| 读完 `guide/05-agent-loop` 想验证理解 | 回头跑 `01-manual-loop` |
| 跑完 `06-mini-agent-cli` 想上线 | 跳到 `project/09` 和 `project/10` |
